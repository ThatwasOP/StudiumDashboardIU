# StudiumDashboardIU
Plattformunabhängiges Python-Dashboard zur Studienorganisation und Echtzeit-Auswertung von ECTS-Fortschritt, gewichtetem Notendurchschnitt, Modulbearbeitungszeit und Leistungstrends für den Studiengang B.Sc. Cyber Security.
## 1. Systemvoraussetzungen

* **Python-Version:** Python 3.10 oder höher (erforderlich durch moderne Type-Hints wie `date | None` und `list[Modul]`; Anwendung wurde entwickelt sowie getestet unter Python 3.12).
* **Externe Abhängigkeiten:** Keine. Es werden ausschließlich Module der Standardbibliothek verwendet.
* **Betriebssystem:** Plattformunabhängig und lauffähig unter Windows, macOS und Linux.

---

## 2. Installation und Start der Anwendung

1. **ZIP-Archiv aus GitHub-Repository in ein Verzeichnis entpacken:**  
   Entpacke das ZIP-Archiv in ein Verzeichnis, sodass alle Programmdateien im gleichen Verzeichnis liegen.

2. **Terminal oder Eingabeaufforderung öffnen:**  
   Navigiere in das Programmverzeichnis:
   ```bash
   cd pfad/zum/projektverzeichnis
   ```

3. **Anwendung starten:**  
   Starte das Dashboard über die Hauptdatei:
   ```bash
   python main.py
   ```
